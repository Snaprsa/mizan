# Report Templates

This directory will contain report templates for Stage 5.

Planned templates:
- `standard_valuation.docx` — Full TAQEEM/RICS-compliant valuation report
- `comparable_summary.docx` — Detailed comparable analysis summary
- `desktop_valuation.docx` — Desktop valuation report
- `market_update.docx` — Market update / opinion of value

Templates use placeholder tokens like `{{subject.city}}`, `{{comparables_table}}`, etc.
