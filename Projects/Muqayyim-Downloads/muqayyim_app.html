Quick Start — Monitoring
Run these commands from the project folder:
# Run monitoring (checks 10+ sources, saves to data/monitoring/)
$ python3 scripts/monitoring/monitor_sources.py

# Collect a specific listing
$ python3 scripts/collection/aqar_collector.py "https://sa.aqar.fm/..."

# Schedule daily monitoring (cron)
$ crontab -e
0 7 * * * cd /path/to/muqayyim && python3 scripts/monitoring/monitor_sources.py
