# Public repository scope

Prepared 28 October 2026. The GitHub repository is a source publication of the consolidated Mizan workspace. The working directory layout is retained to preserve the live adapter and existing functionality.

## Included

Active application source, frontend lockfile, migrations, reusable calculation engines, earlier prototype source, automated tests, blank configuration examples, architecture notes, the product scope and the full satellite-map/interface implementation prompt.

## Kept local

Private SQLite databases and journals; runtime uploads/backups; real `.env` files; provider cookies/sessions; personal file-location logs; saved third-party pages; screenshots; model binaries; raw datasets/indicator workbooks and review materials with unverified redistribution rights; installed dependencies and generated private handoff ZIPs.

These exclusions are deliberate. A public clone starts with an empty database and no trained model or live transaction feed. The existing dataset inventory discovers locally available files; its count can be zero on a public checkout. No fictional market records are seeded to conceal the difference.

The full original-location TSV, move history and collection manifest remain in the owner's local workspace. They are not published because they contain personal machine paths and extensive dependency inventories. This public map preserves the component lineage without exposing those paths.

## Share and transfer

Share the repository URL, or use GitHub's **Code → Download ZIP**. Both contain only committed public files. For another LLM, attach that ZIP and begin with `00_START_HERE.md` and `handoff/UPGRADE_PROMPT.md`.

Do not publish the separately generated private handoff ZIP from the original workspace as a public release. It has a different scope and includes unreviewed reference data and detailed local provenance. Use `git archive` for a release of the reviewed public source.

The repository is public source for collaboration. No open-source license has been selected in this publication; do not invent a license or assume external dataset redistribution rights.
